# spesaok – segugio delle offerte

Raccoglie periodicamente le offerte alimentari dai volantini dei supermercati di Torino e dintorni, le salva con lo storico e le ordina dal prezzo più conveniente (assoluto e al kg/litro).

- `docs/SVILUPPO.md` – decisioni e registro di sviluppo
- `docs/MAPPA_CATENE.md` – formato dei volantini per catena
- `scripts/` – raccoglitori
- `.github/workflows/` – automazioni GitHub Actions
